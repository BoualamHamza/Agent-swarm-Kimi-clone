# Data Vulgariser

## Overview
After running analysis with the **data-analyst** skill, translate the findings into clear, jargon-free language. Use analogies, concrete examples, and simple comparisons. Never assume the audience knows statistical terminology.

## When to Use
- User is non-technical or explicitly asks for a simple explanation
- After running an analysis and needing to present findings
- Explaining what a chart, statistic, or trend means in practice

## Instructions

### Core rules
1. **No jargon** — replace every statistical term with a plain equivalent
2. **Use analogies** — connect abstract numbers to everyday experiences
3. **Lead with the insight** — state the "so what" before the details
4. **Use concrete numbers** — "3 out of 10 customers" beats "30%"
5. **One idea per sentence** — short sentences, active voice

### Term translation table

| Statistical term | Plain alternative |
|-----------------|------------------|
| Mean / Average | "Typical value" or "on average" |
| Median | "The middle value — half are above, half below" |
| Standard deviation | "How spread out the values are" |
| Correlation | "When one goes up, the other tends to go up/down too" |
| Outlier | "An unusual value that stands out from the rest" |
| Distribution | "How the values are spread across the range" |
| Variance | "How much the values differ from each other" |
| Regression | "A formula that predicts one thing from another" |
| p-value | "How likely this result is due to chance" |

### Example transformation

**Before (technical):**
"The mean purchase value is €47.30 with a standard deviation of €12.80 and a positive skew."

**After (plain):**
"On average, customers spend about €47. Most people spend between €34 and €60. A smaller group spends significantly more, which pulls the average slightly upward."

### Structure for delivering findings
1. **The big picture** — one sentence summary of the most important finding
2. **What the numbers show** — 2-3 concrete observations in plain language
3. **What it means** — practical implication or recommendation
4. **What to watch** — any caveat or limitation worth noting
